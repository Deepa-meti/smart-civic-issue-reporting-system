# Smart Civic Issue Reporting System - Project Documentation

## 1. Project Overview

The Smart Civic Issue Reporting System is a web application that enables citizens to report civic issues such as potholes, garbage accumulation, damaged roads, water leakage, and broken streetlights. The application allows users to submit complaints, track their status, and provides an admin interface for managing and resolving reported issues.

---

## 2. Problem Statement

Citizens often face difficulties reporting civic issues and tracking whether their complaints have been resolved. This project aims to provide a simple, transparent, and user-friendly platform that connects citizens with local authorities.

---

## 3. Project Objectives

* Provide an easy way for citizens to report civic issues.
* Allow users to monitor the status of their complaints.
* Enable administrators to manage and update reported issues.
* Build a responsive and user-friendly web application.
