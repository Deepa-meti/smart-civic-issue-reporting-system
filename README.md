# Smart Civic Issue Reporting System

## Project Overview

The Smart Civic Issue Reporting System is a web application designed to help citizens report civic problems such as potholes, garbage dumps, water leakage, damaged roads, broken streetlights, and other public issues. The system allows users to submit complaints, track their complaint status, and enables administrators to manage and resolve issues efficiently.

## Objectives

* Make it easy for citizens to report civic issues.
* Allow users to track the progress of their complaints.
* Provide an admin panel to manage reported issues.
* Build a clean, responsive, and user-friendly application.
